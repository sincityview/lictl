# Plan: Configurable cloud-init password

## Problem
Hardcoded `deploy:deploy` password in cloud-init. Need to make it configurable or remove it.

## Changes

### 1. Add `password` field to CIUser
**File:** `internal/config/schema.go:107-113`

Add `Password string` field to `CIUser` struct:
```go
type CIUser struct {
    Name          string   `yaml:"name"`
    SSHPublicKeys []string `yaml:"ssh_authorized_keys,omitempty"`
    Password      string   `yaml:"password,omitempty"`
    Sudo          bool     `yaml:"sudo,omitempty"`
    Shell         string   `yaml:"shell,omitempty"`
    LockPassword  bool     `yaml:"lock_password,omitempty"`
}
```

### 2. Update cloud-init generator
**File:** `internal/libvirt/cloudinit.go:146-151`

Replace hardcoded `chpasswd` with conditional logic:
- If any user has `password` set → write `chpasswd` section with that password
- If no user has `password` → skip `chpasswd` entirely (SSH keys only)

### 3. Remove hardcoded password
The hardcoded `deploy:deploy` block gets removed by the conditional logic above.

## YAML examples

Password specified:
```yaml
cloud_init:
  users:
    - name: deploy
      password: mySecret123
      ssh_authorized_keys:
        - ssh-ed25519 AAAA...
```

No password (SSH only):
```yaml
cloud_init:
  users:
    - name: deploy
      ssh_authorized_keys:
        - ssh-ed25519 AAAA...
```
